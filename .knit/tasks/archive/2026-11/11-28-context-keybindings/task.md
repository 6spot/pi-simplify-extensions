## 目标与范围

用户确认接入此前暂缓的快捷键。在 `/context` 主弹窗与文本预览中，通过 Pi 的实际绑定处理选择、确认、关闭以及已有的翻页动作，并让屏幕提示与实际按键对应。

## 完成条件

### Requirement: 自定义绑定与弹窗操作一致

#### Scenario: 使用默认、自定义或清空的选择器绑定

- WHEN 打开 `/context`，选择一个分类、打开预览并返回
- THEN 弹窗识别当前配置的按键，提示能反映改键和清空的状态，鼠标可继续选择、复制和关闭

## 结果

两个弹窗从 Pi 的 ui.custom 读取实际绑定，按配置处理选择、确认、关闭、逐行滚动和翻页。关闭和复制按钮按显示列定位，清空关闭键后仍可点击 [close]。从锁文件安装后类型检查、348 项全量测试和 git diff --check 通过。在独立配置的本机 Pi 1.7.0 普通与全屏模式中验证了默认操作、/reload 改键和清空绑定、别名生效、鼠标选行和关闭、复制按钮与相邻空格的悬停边界。
