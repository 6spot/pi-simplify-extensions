## 目标与范围

修正 `/context` 中隐藏工具的声明估算和预览。对照上游 v1.0.20 的展开面板优化，测量 Simplify 的分组重绘、流式输出和鼠标定位，减少内容未变时的重复工作。按用户确认的样式，展开分组的相邻工具之间留一行，保留原有间隔和图片占位。

## 完成条件

- 隐藏、全部隐藏和未指定隐藏工具的输入都得到对应的声明统计与预览。
- 相同可见内容可复用；新输出、状态切换、宽度或主题变化仍触发所需更新。
- 展开分组的间隔、鼠标定位与图片占位一致，保留折叠和独立面板的既有布局。
- 在相同负载下对照前后渲染和命中成本，运行项目类型检查、测试与 Git 检查，记录实测范围。

## 待澄清

已确认建档、实施与展开组间距。

## 相关资料

- 上游展开面板优化 `be51c02`，展开分组间距 `018acf1`，隐藏工具统计 PR #106。

## 结果

已按任务中的四项完成条件自验。`/context` 从选中工具中移除 Pi 隐藏的声明，定义估算和原文预览共用结果。展开分组按子工具实际绘制行与状态复用整帧，鼠标按已绘制的行高定位。相邻工具之间留一行，子项自带的树线间隔计作这一行。Kitty 和 iTerm2 的占位归图片工具，包括只含树线的占位行。

### 性能对照

基线为 `aeef79d`，运行 Node 26.3.0。分别使用仓库锁定的 Pi 1.5.2 和本机安装的 Pi 1.6.0。100 列终端中展开六个真实 Read 组件，每项 16 行中英文与 emoji，第六项保持流式。稳定重绘连续调用 render，更新负载每帧替换最后一项输出。会话命中负载在分组前放一条 200 行的展开思考。每个负载先预热 12 次，每进程取 5 组样本中位数，再取 3 次独立进程的中位数。表中单位均为毫秒/次。

| 负载 | Pi 1.5.2 改前 | 改后 | Pi 1.6.0 改前 | 改后 |
| --- | ---: | ---: | ---: | ---: |
| 流式期间相同画面重绘 | 1.53305 | 0.01604 | 0.03477 | 0.01627 |
| 每帧更新最后一项输出 | 1.68183 | 0.17983 | 0.20114 | 0.18010 |
| 直接命中分组末项 | 0.04787 | 0.00025 | 0.04705 | 0.00027 |
| 全部完成后重复重绘 | 0.01171 | 0.00198 | 0.01104 | 0.00147 |
| 经会话容器命中分组末项 | 0.24036 | 0.00120 | 0.24531 | 0.00151 |
| 单独重绘前置的 200 行思考 | 0.17472 | 0.18865 | 0.17271 | 0.25668 |

首次单进程摸底在 Pi 1.5.2 上测得稳定重绘 3.410 ms、输出更新 2.318 ms。上表采用最终配对复测。两版本的分组均从 99 行变为 104 行，对应五个工具间隔。Pi 1.5.2 在改前对相同的流式行返回新数组，改后复用。Pi 1.6.0 在此负载下已有原生行缓存。思考正文渲染路径未作修改，独立渲染数据有波动，此项未测得稳定改善。
